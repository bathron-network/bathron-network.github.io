# Network status

This page is the single canonical source for the state of the BATHRON network. Other pages and repositories link here instead of restating it.

*Last updated: 5 October 2026.*

The DMM public testnet was shut down on 5 October 2026. A new network using consensus engine N is under construction. No launch date has been announced.

Release packages, seed addresses and genesis hashes published for the DMM public testnet refer to that network only and are kept as historical references.
