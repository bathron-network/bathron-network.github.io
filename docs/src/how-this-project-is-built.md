# How this project is built

> **Sources:** Project-owner statements on this page; [N-SPEC v0.7 §12.11][n1211] for the release-key policy; [Network status](status.md) for network availability.
> This page describes how the project is maintained and how its work is published.

BATHRON is an independent project, maintained anonymously; there is no company or foundation today.

## How the work is produced

BATHRON is designed and built by a craftsman working with AI models, Anthropic Claude and OpenAI Codex, that write, review and challenge each other's work. Specification, code and analyses are produced this way, and the file names in the repositories reflect it.

## Independent review

This process does not replace independent human review. No external audit has been done yet; an external audit is a precondition before any public network carries value. Model reviews and internal checks do not constitute an external audit.

## Bootstrap keys

Key holders for the bootstrap keys (3-of-4) will be published before the public testnet. The release-key policy calls for public information about custody, responsibilities and administrative dependencies; separate keys do not establish independent administration. [N-SPEC v0.7 §12.11][n1211]

## Public history

The code repository is a controlled export. No weakness is described in public until it is fixed. This is the reason for controlling what enters the public history.
